# Setup page

`template.html` is the served pairing page at `/umbrel`. It is a single
column: password form, a "Set up T3 Connect" card, and an "Already paired" link.
Graphite neutrals, one off-white action, monospace details. No React runtime.

```sh
npm run build:setup # regenerate container/welcome.mjs
```

`screenshots/` shows the page at 1280 and 390 px wide.
